# vibeos

Minimal NixOS flake for Zell, currently covering WSL plus a Gallifrey headless host skeleton.

## Layout

- `flake.nix`
- `hosts/wsl/default.nix`
- `hosts/gallifrey/default.nix`
- `hosts/gallifrey/disko.nix`
- `hosts/gallifrey/hardware-configuration.nix`
- `hosts/gallifrey/nixos-anywhere.nix`
- `modules/nixos/base.nix`
- `home/zell/default.nix`
